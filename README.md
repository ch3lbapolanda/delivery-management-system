# Kurir Malam 🌙

**Delivery Management System**

Kurir Malam is a delivery management platform designed to manage delivery operations, couriers, customers, and shipment tracking.

## Tech Stack

### Backend
- Laravel
- PHP
- MariaDB / MySQL
- Laravel Sanctum
- REST API
- Role-Based Access Control (RBAC)

### Frontend
- Nuxt 4
- Vue 3
- TypeScript

## Project Structure

```text
kurir-malam/
├── delivery-api/    # Laravel Backend
├── delivery-web/    # Nuxt Frontend
├── .gitignore
└── README.md
```

## Current Features

- User registration and authentication
- Token-based authentication with Laravel Sanctum
- Role-based authorization
- Admin, Dispatcher, Courier, and Customer roles
- Frontend and backend API integration
- Dark-themed Kurir Malam interface
